 Formulário com Envio para WhatsApp

Formulário web desenvolvido para facilitar o preenchimento e envio de informações diretamente para o WhatsApp.

## 🚀 Sobre o projeto

O projeto permite que o usuário preencha um formulário com as informações solicitadas e, ao finalizar, os dados são organizados e enviados diretamente para o WhatsApp de forma prática e rápida.

A aplicação foi desenvolvida com foco em uma interface simples, intuitiva e responsiva.

## 🛠️ Tecnologias utilizadas

- ⚛️ React
- 🟨 JavaScript
- 🟧 HTML5
- 🟦 CSS3
- ⚡ Vite

## ✨ Funcionalidades

- Preenchimento de formulário
- Seleção de informações
- Validação dos campos
- Organização das informações preenchidas
- Envio dos dados diretamente para o WhatsApp
- Interface responsiva
- Componentização com React
